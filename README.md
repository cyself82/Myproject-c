# SOXL 매매 신호 프로그램 안내

> 공부용 도구입니다. 투자 조언이 아니며, 실제 매매 결정과 손실 책임은 본인에게 있습니다.

## 1. 백테스트가 뭔가요?

**"이 규칙대로 과거에 샀다 팔았다면 어떻게 됐을까?"를 컴퓨터로 시뮬레이션해 보는 것**입니다.

예를 들어 "SOXL이 200일 평균가격 위에 있으면 들고 있고, 아래로 내려가면 판다"는 규칙이 있다면, 2010년부터 지금까지 매일 이 규칙을 적용해서

- 최종적으로 돈이 몇 배가 됐는지
- 중간에 최대 몇 % 까지 깨졌는지 (최대낙폭, MDD)
- 몇 번이나 사고팔았는지

를 계산합니다. 그리고 "그냥 사서 계속 들고 있기"와 비교해서 규칙이 정말 도움이 되는지 확인합니다.
과거에 잘 됐다고 미래에도 잘 된다는 보장은 없지만, **과거에도 안 된 규칙은 쓰지 않는 게** 기본입니다.

## 2. SOXL을 꼭 알고 시작하세요

- SOXL은 반도체 지수의 **하루 수익률을 3배**로 따라가는 레버리지 ETF입니다.
- 지수가 10% 오르면 약 30% 오르지만, 10% 빠지면 약 30% 빠집니다.
- 오르락내리락만 반복해도 가치가 녹는 성질(변동성 손실)이 있어서 **오래 묵혀두기에 위험한 상품**입니다.
- 2022년 하락장에서는 고점 대비 약 -90% 수준까지 떨어졌습니다(기억 기반 대략치, 프로그램으로 직접 확인 가능).
- 그래서 "손해 본 종목을 계속 들고 있는" 습관과 가장 상극인 상품입니다. **규칙대로 파는 것**이 핵심입니다.

## 3. 프로그램이 비교하는 전략

| 전략 | 규칙 | 성격 |
|---|---|---|
| 그냥 사서 보유 | 처음에 사고 끝까지 보유 | 비교 기준 |
| SOXL 200일선 | SOXL 종가가 200일 평균 위면 보유, 아래면 현금 | 추세 추종 |
| SOXX 200일선 | 1배 반도체 ETF(SOXX)가 200일 평균 위면 SOXL 보유 | 추세 추종, 신호가 덜 흔들림 |
| **골든/데드크로스 50·200 (기본)** | 50일 평균이 200일 평균 위로 가면 매수, 아래로 가면 매도 | 느린 추세 추종 |
| RSI 역추세 30/70 | RSI 30 아래(과매도)에서 매수, 70 위(과매수)에서 매도 | 저점 매수 |

모든 전략에 **손절 -20%** 가 붙어 있습니다. 산 가격보다 20% 빠지면 무조건 팔고, 매수 조건이 한 번 꺼졌다 다시 켜질 때까지 쉽니다.
매매할 때마다 비용 0.1%를 빼고 계산하며, 오늘 신호는 다음 날 수익률부터 반영해서 "미래를 미리 보는" 착시를 막았습니다.

**기본값을 골든/데드크로스로 둔 이유:** 실제 데이터 백테스트에서 그냥 보유와 거의 같은 수익을 내면서 최대낙폭은 -90%에서 -69%로 줄였고, 16년 동안 매매가 19번뿐이라 초보자가 지키기 쉽습니다. (처음엔 SOXX 200일선을 기본으로 뒀지만 실제 결과가 더 나빠서 바꿨습니다.)

## 4. 사용 방법 (내 PC에서)

`Y:\Claude\run_soxl.bat`을 더블클릭하면 바로 실행됩니다. 명령창에서 옵션을 주려면:

```bash
.venv\Scripts\python.exe soxl_signal.py            # 전략별 백테스트 표 + 오늘의 신호
.venv\Scripts\python.exe soxl_signal.py --signal   # 오늘의 신호만
.venv\Scripts\python.exe soxl_signal.py --plot     # 수익 곡선 그림(soxl_backtest.png) 저장
.venv\Scripts\python.exe soxl_signal.py --stop 0   # 손절 없이 비교
.venv\Scripts\python.exe soxl_signal.py --start 2018-01-01   # 기간 바꿔서 비교
```

오늘의 신호는 이렇게 나옵니다.

- 🟢 **매수 신호**: 오늘 새로 진입 조건이 켜짐
- 🔴 **매도 신호**: 오늘 청산 (추세 이탈 또는 손절)
- **보유 유지 / 현금 대기**: 상태 변화 없음

미국장 마감 후(한국 시간 아침) 한 번 돌리고, 신호가 바뀐 날만 행동하면 됩니다.

**해석**
- 지난 16년은 반도체 역사상 최고의 상승기였습니다. 그래서 "그냥 보유"가 이렇게 좋게 나왔지만, 중간에 -90%를 견뎌야 했습니다. 실제로 -90%를 버티고 계속 들고 있을 수 있는 사람은 거의 없습니다.
- 골든/데드크로스는 수익은 거의 같고 최대낙폭은 20%p 작습니다. 그래도 -69%는 여전히 매우 큰 손실이라, SOXL은 전체 자산의 작은 일부로만 두는 게 맞습니다.
- 200일선 전략들은 매매가 너무 잦아(100번 이상) 손해를 봤습니다. RSI 저점 매수는 3배 상품과 잘 안 맞았습니다.
- 과거 결과가 미래를 보장하지 않습니다.
